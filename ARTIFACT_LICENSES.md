# Artifact license notes

This anonymous package does not grant rights to upstream datasets or baseline
repositories. TrainTicket, AIOps2022, and each upstream method remain governed
by their source terms. The frozen protocol records MIT for MicroRank and Nezha,
Apache-2.0 for mABC, and “no explicit license in snapshot” for MicroRCA, Eadro,
and TraceAnomaly. The latter source snapshots are intentionally omitted.

The package is supplied to the review committee for artifact evaluation. A
public code license will be added to the authors' repository upon de-anonymized
release; it is not inferred here on behalf of the authors.
