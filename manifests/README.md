# CARE submitted cohort manifests

These files are non-executable supplemental records for the paper. They disclose
the exact current incident queues, split assignments, overlap groups, candidate
order, telemetry channel order, log-template inventory, evidence-feature order,
held-type fold counts, source hashes, and deterministic cohort construction.
They contain no confidential PM data and do not assert equivalence to an earlier
unavailable AIOps split.
